# HeaderAndLint.Generator

Shows the two options that shape the first lines of a generated file, configured with the fluent API in
`GeneratorMain.cs`. `NoHeaderVersion()` writes the `<auto-generated>` header without the version of
the generator, so every file of the write names the generator alone. The first and the third chain
configure nothing for the linter and come out with the comment of their language - `/* eslint-disable */`
for TypeScript in `Output/Models`, `// ReSharper disable All` for C#. The second chain writes the same
model to `Output/Legacy` in both languages and scopes the replacement to one of them with
`SuppressLint("// @ts-nocheck", nameof(OutputLanguage.TypeScript))`, so the TypeScript file carries
`// @ts-nocheck` while the C# file of the same write keeps `// ReSharper disable All`.
