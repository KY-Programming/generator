# HeaderAndLint

Shows the two options that shape the first lines of a generated file, configured with annotations.
`[assembly: GenerateNoHeaderVersion]` in `AssemblyInfo.cs` writes the `<auto-generated>` header
without the version of the generator, so every file in the project names the generator alone.
`Source/WeatherForecast.cs` and `Source/ContactDto.cs` carry no linter configuration and come out with
the comment of their language - `/* eslint-disable */` for TypeScript, `// ReSharper disable All` for
C#. `Source/LegacyForecast.cs` is written in both languages and replaces the comment of one of them with
`[GenerateSuppressLint("// @ts-nocheck", nameof(OutputLanguage.TypeScript))]`, so its TypeScript file
carries `// @ts-nocheck` while its C# file keeps `// ReSharper disable All`.
