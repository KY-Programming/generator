# NonStrict.Generator

The fluent counterpart to Annotation/NonStrict. Two write chains read the same model: the first one is left
alone and is therefore generated for TypeScripts strict mode - the default - into Output/Strict, the second
one calls NonStrict() and writes the opted out variant into Output/NonStrict. NonStrict() applies to the
whole write chain, so per type control needs the [GenerateNonStrict] annotation instead.

Matching output hashes only prove that nothing changed - not that the generated TypeScript compiles. validate.js type-checks the generated models against the shared tsconfig in Tests/Shared as the last build step and reports its result as JSON on the last line of its output.
