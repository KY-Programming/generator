# WatchdogTimeout

Covers a wait that never succeeds: the fluent `WaitFor(...)` points at a port nothing listens on, so it can only run into its timeout. Model.cs and the read/write chain behind the wait would produce Output/model.ts, and that is what must not happen - a generation whose wait failed writes nothing and reports the failure, so the build fails and the output folder stays empty.
