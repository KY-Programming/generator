# TypeScriptValidationStrict

Type-checks the generated output of the other v10 projects against strict plus the additional TypeScript checks.
Shared/Scripts/build-file-list.js writes tsconfig.generated.json (gitignored) with every output file that was
generated with GenerateStrict. Whether a file is strict is read from the C# sources - [assembly:GenerateStrict] or
[GenerateStrict] on the class itself - so new output is picked up automatically. Files generated without
GenerateStrict are covered by TypeScriptValidationNotStrict instead. The generated Angular output is checked
against the real @angular/* and rxjs types: Shared/Scripts/ensure-packages.cmd installs the pinned packages from
Tests/v10/package.json before tsc runs.

This project has no csproj and generates nothing - it is verified by a script instead of by output hashes.
Validate/validate.cmd reports its result as JSON on the last line of its output: the error count becomes the
project info, the number of type-checked files the output marker.
