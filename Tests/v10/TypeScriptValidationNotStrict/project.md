# TypeScriptValidationNotStrict

Counterpart to TypeScriptValidationStrict for the output that was generated without GenerateStrict, so it is
checked against the settings it was actually generated for. tsconfig.json switches strict off and
Shared/Scripts/build-file-list.js writes tsconfig.generated.json (gitignored) with every compilable output file -
a superset of the strict list, since strict output is valid under a non strict tsconfig too. The generated Angular
output is checked against the real @angular/* and rxjs types: Shared/Scripts/ensure-packages.cmd installs the
pinned packages from Tests/v10/package.json before tsc runs.

This project has no csproj and generates nothing - it is verified by a script instead of by output hashes.
Validate/validate.cmd reports its result as JSON on the last line of its output: the error count becomes the
project info, the number of type-checked files the output marker.
